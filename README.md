# Pewnie — польська B1/B2: мовлення й письмо

Тренажер до державного іспиту з польської мови як іноземної (certyfikat B1/B2) з акцентом на **усну й письмову частини**. Статичний сайт без сервера, без реєстрації й без збору даних: увесь прогрес живе в браузері користувача.

**Дизайн:** «зошит і червоний олівець» (світла тема) та «крейдяна дошка» (темна).

## Що вміє

| | |
|---|---|
| **Мовлення** | Три формати іспиту: опис ілюстрації, монолог, ситуативна розмова. Підготовка з таймером і нотатками → запис голосу з «хвилями» → авто-транскрипт (Chrome/Edge/Safari) → розбір: час, темп, слова-мішені, зв’язки, кальки, паузи → самооцінка → модельна відповідь з озвученням і shadowing по реченнях. Діалоги — з «екзаменатором», який говорить польською (Web Speech API). |
| **Письмо** | Редактор-зошит із польськими літерами, таймером і лічильником слів у межах ліміту. «Червоний олівець»: пункти завдання, регістр, звертання/прощання, коми, діакритика, типові помилки україномовних (`pracuję jako lekarzem`, `mnie podoba się`, `w Ukrainie`…), різноманіття зв’язок і конструкцій, орієнтовна оцінка за 4 критеріями зі шкалою 1–6. Правки застосовуються одним кліком. Кнопка «Розбір від ШІ-вчителя» копіює готовий запит для ChatGPT/Claude. |
| **Слухання, читання, граматика** | Тести з поясненнями до кожної відповіді; аудіо — озвучення в браузері, двічі, як на іспиті. |
| **Слова** | Картки з інтервальним повторенням (Leitner), озвучення слів і прикладів. |
| **Довідник** | Формат іспиту, стратегії, зв’язки, шаблони листів, фрази для усної, «хибні друзі», типові помилки. |
| **Прогрес** | Серія днів, оцінки за навичками, експорт/імпорт файлом, PWA (працює офлайн). |

## Як з’являються нові завдання щотижня

Кожен тиждень — це два файли `content/weeks/<id>.b1.json` / `<id>.b2.json` і рядок у `content/index.json` з датою релізу (понеділок). **Сайт сам відкриває тижні за датою** — жодних деплоїв «у понеділок» не потрібно, тому контент можна писати наперед.

Щоб черга не закінчувалась:

1. **Вручну:** додати файли тижня й запис у `content/index.json`, запустити `npm run validate`.
2. **Автоматично (`scripts/github-workflows/weekly.yml`):** щопонеділка воркфлоу перевіряє «запас» майбутніх тижнів і, якщо їх менше 4, викликає Claude API (`scripts/generate-week.mjs`) для нового тижня наступної теми зі `scripts/themes.json`. Результат публікується **лише якщо пройшов валідатор** (структура + модельні відповіді проганяються через той самий аналізатор, що бачить учень); інакше зміни скасовуються. Потрібен секрет репозиторію `ANTHROPIC_API_KEY` (Settings → Secrets and variables → Actions). Без ключа воркфлоу просто нічого не робить.

   > **Увімкнення:** файли лежать у `scripts/github-workflows/`, бо токен, яким публікували репозиторій, не мав scope `workflow`. Щоб активувати: `gh auth refresh -s workflow`, потім `mkdir -p .github && git mv scripts/github-workflows .github/workflows && git commit -am "enable workflows" && git push`.

## Голос

Озвучення — це **заздалегідь згенеровані нейронні записи** (`content/audio/*.mp3`, голоси `pl-PL-ZofiaNeural` і `pl-PL-MarekNeural`), тож звучить однаково на будь-якому пристрої й не залежить від голосів системи. Кліп визначається хешем тексту (`js/textutil.js`); якщо кліпа немає — сайт мовчки переходить на голос системи. Чоловічий голос — екзаменатор і співрозмовники в аудіюванні, жіночий — решта.

```bash
pip install edge-tts
node scripts/build-audio.mjs             # згенерувати те, чого бракує (інкрементально)
node scripts/build-audio.mjs --check     # лише порахувати прогалини
node scripts/build-audio.mjs --provider azure   # офіційний Azure AI Speech (ті самі голоси): AZURE_SPEECH_KEY + AZURE_SPEECH_REGION
```

> `edge` — безкоштовний, але неофіційний ендпоїнт Microsoft: підходить для прототипу. Для комерційного продукту перегенеруйте кліпи через `--provider azure --force` (голоси ті самі, умови використання — офіційні).

## Локально

```bash
npm install            # лише для генератора тижнів
npm run serve          # http://localhost:8765
npm run validate       # перевірка всього контенту
```

Корисні параметри URL для тесту: `?today=2026-09-07` (підмінити дату), `?preview` (відкрити всі тижні).

## Структура

```
index.html · css/ · js/        — застосунок (ES-модулі, без збірки)
js/analyze.js                  — «червоний олівець» для письма й мовлення
js/speech.js                   — озвучення, запис, розпізнавання
content/index.json             — календар тижнів
content/weeks/*.json           — завдання (по файлу на рівень)
content/toolkit.json           — довідник
scripts/validate.mjs           — перевірка контенту
scripts/generate-week.mjs      — генерація нового тижня через Claude API
scripts/build-audio.mjs        — нейронне озвучення (content/audio)
scripts/github-workflows/      — CI (валідація) і щотижневе поповнення черги
sw.js · manifest.webmanifest   — офлайн і PWA
```

## Чесно про обмеження

- Незалежний проєкт, **не пов’язаний** з Державною комісією з посвідчення знання польської мови як іноземної. Формат наближено до відкритих описів (universities + certyfikatpolski.pl); **актуальні вимоги перевіряйте на офіційному сайті**. Справжніх іспитових завдань тут немає.
- Автоматична оцінка письма/мовлення — це **формальні ознаки** (обсяг, структура, зв’язки, типові помилки), а не розуміння змісту. Вона не замінює екзаменатора чи репетитора.
- Розпізнавання мови виконує браузер: Chrome/Edge надсилають звук на розпізнавання в хмару розробника, Safari — в Apple. Без нього сайт працює як диктофон із ручним транскриптом.
- Озвучення потребує польського голосу в системі. Якщо його немає — додайте в налаштуваннях ОС.
- Контент — статичні JSON-файли: захисту від копіювання немає. Для платної підписки знадобиться серверна частина (автентифікація й видача контенту).
- Польський текст написано з допомогою ШІ і перевірено автоматично, але **не вичитано носієм мови**.
